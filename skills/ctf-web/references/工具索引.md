## 本类工具

> 工具以 $PI_LAB_ROOT/tools/TOOLS.md 为准；tools/bin 已在 PATH 里，命令名直接用。

```
# 侦察 / 指纹 / 爬虫
httpx -l hosts.txt -title -tech-detect -o alive.txt   # 存活 / 标题 / 技术栈
nuclei -l alive.txt -t http/ -o nuclei.txt            # 模板化漏洞扫描
katana -u https://目标 -jc -o urls.txt                # 爬 URL / 表单 / JS 端点
gau 目标.com | sort -u                                # 历史 URL
enscan -d 目标.com                                    # SRC 资产收集
naabu -host 目标.com -top-ports 1000                  # 端口扫描
wafw00f / cmseek / graphw00f / hashid                 # WAF / CMS / GraphQL / 哈希类型
subjack / masscan / urlfinder                         # 子域接管 / 大网段 / JS 抠接口

# 目录爆破 / 口令
dirsearch -u https://目标 -e php,html,js,bak
feroxbuster -u https://目标
ffuf -u https://目标/FUZZ -w $PI_TOOLS/wordlists/dirsx/dicts/fuzzing-dirs-common.txt
hydra -l admin -P <弱口令字典> <目标> http-post-form

# Web 漏洞利用
sqlmap -u "<url>" --batch
commix --url="https://目标/?id=1"
dalfox url https://目标/?q=1
xsstrike / ssrfmap / tplmap / xxeinjector / jwt_tool / pocbomber

# 源码 / 版本库泄露
githack https://目标/.git/
rip-git -u https://目标/.git/ -v
svnexploit / rip-svn / rip-hg / rip-bzr / rip-cvs / dumpall / jsfinder

# 本地 POC 索引（真实可用）
poc "<组件>"              # 组件/CVE → 本地 POC（请求骨架 + 判定式）
poc --cve CVE-xxxx-xxxx   # 按 CVE 查
```
系统命令已装：`curl wget nmap ffuf sqlmap john hashcat git unzip 7z python3 pip3 ruby perl gcc gdb readelf objdump strings file openssl binwalk exiftool tshark steghide zsteg tesseract nc socat r2 node`。
Python 库已装：系统 `python3` 有 `requests bs4 lxml yaml sympy numpy scipy PIL capstone`；`py`（= tools/venv/bin/python）另有 `pwn z3 Crypto gmpy2 ecdsa ropgadget unicorn`——要 pwn/z3/Crypto 的脚本用 `py` 跑，系统 `python3` 没有这些库。
