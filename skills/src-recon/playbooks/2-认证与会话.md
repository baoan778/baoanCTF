# 品类 2 · 认证与会话（JWT / OAuth / 账号接管 / 验证码）

> **为什么是独立品类**：认证类漏洞的**危害是天然的**（不需要再证明"能拿到数据"）——
> 拿到会话即接管，判据比越权简单。SRC 里这类报价通常最高。
> 来源：PortSwigger JWT/OAuth · `yaklang/hack-skills` jwt-oauth / oauth-oidc · `PayloadsAllTheThings`。

## 何时用
- 登录/注册/找回密码/改绑手机/第三方登录（OAuth）流程
- 请求里出现 `Authorization: Bearer` / cookie 里的三段式 base64（`eyJ...`）
- 参数里有 `state` / `redirect_uri` / `code` / `id_token` / `response_type`

## 探测（本机工具）

```bash
# JWT 结构一眼看全（别手工 base64）
python3 -c "import base64,sys,json;[print(json.dumps(json.loads(base64.urlsafe_b64decode(s+'='*(-len(s)%4))),ensure_ascii=False,indent=1)) for s in sys.argv[1].split('.')[:2]]" "$TOKEN"

# 弱密钥爆破
hashcat -m 16500 jwt.txt rockyou.txt          # HS256 密钥 <32 字节通常秒出

# 公钥来源（jku/jwk 攻击的前提）
curl -s https://T/.well-known/jwks.json | head -c 400
curl -s https://T/.well-known/openid-configuration | head -c 600
```

## 判据（每条的"成功"定义不同，别混）

| 攻击 | 判据（**必须到这一步才算**） |
|---|---|
| `alg:none` | 伪造 token **访问到了需认证资源**（不是"token 被接受"） |
| **RS256→HS256 混淆** | 用**服务端公钥当 HMAC 密钥**重签后，能访问受保护资源 |
| **`kid` 注入** | 路径穿越（`../../../../dev/null` → 空密钥）或 SQLi（`' UNION SELECT 'knownkey'--`）后**签名可自控** |
| `jku`/`x5u` | 起自建 JWKS（`python3 -m http.server` + 自签 JWKS），`jku` 指过去后**服务端真的取你的键** |
| 弱密钥 | hashcat 出密钥 → 重签 → 访问成功 |
| **OAuth `state` 缺失** | **能用自己账号的 code 让受害者账号绑到攻击者身份**（登录 CSRF）→ 账号接管 |
| `redirect_uri` 绕过 | 后缀（`https://t.com.evil.com`）/ 路径穿越（`/cb/../evil`）/ 参数污染（`?redirect_uri=good&redirect_uri=evil`）/ 空字节 → **code 落到自己域** |
| **ID Token 不验签** | 改 `sub` 后**变成别人** |
| 密码重置 | token 在响应里回显 / Host 头注入改重置链接域 / 用完不失效 / 并发用同一 token |
| 验证码 | 图形码回显 = `ignored`；**短信 OTP 回显 = 成立**；短信轰炸 = `ignored` |

## 账号接管链（把单品拼成链，这才是 SRC 想要的）

```
抢绑 / 改绑 / 解绑 三件套凑齐 = 接管链
  robAndBind（抢绑第三方） + modifyBindMobile（改绑手机号） + unbindByToken（解绑他人）
→ 判据：能用自己的身份，让目标账号的绑定关系变成我的
```
**步骤**：① 三个接口分别无 Cookie 裸打（看是否 401）② 带自己会话打他人标识 ③ 用改绑后的账号**登录成功**。

## 坑
- **`kid`/`jku` 的 payload 常有 JSON 转义/编码要求**：先手工构造一个能过的，再批量
- **`wx.login` 的 code 是一次性的**：重放失败**不算漏洞**
- **前端加密 ≠ 后端安全**：`sign`/`encrypt` 的 JS 就在包里能复现，但**只有能造成危害才算洞**
- **改响应包绕登录是弱证据**：进去了但只能看自己的数据 → `ignored`

## 证据怎么留
```bash
fgs fact-add <pid> "<接管链结论>" --confidence verified --verdict accepted \
    --severity critical --proof-kind authz_diff --target <host>
```
**接管类必须留**：伪造的 token/请求 + 成功回执（登录成功页/接口返回他人数据）。
**写类**（改绑/解绑）走无害证据：**只用自己账号**，改完立刻改回（`idempotent`）。
