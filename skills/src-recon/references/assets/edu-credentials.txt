## ── 登录逻辑缺陷（比弱口令更值钱，命中即高危）──
# 1) 前端误用 hash 当密码：服务端存 MD5，前端再 MD5 一次 → 把 MD5 串当明文提交即可登录
# 2) 任意密码可登录：登录框不校验密码内容（案例：随便填字符串都进）
# 3) 忘记密码前端校验绕过：抓返回包把 false→true / code 0→1 / msg 1→2 逐个试
# 4) 账号申诉滥用：开放「账号申诉」的站点，用收集到的 sfz/学号重置他人密码（需对照账号）
