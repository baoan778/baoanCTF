# 黑板四节点与三任务的契约

> 从 `fgs-orchestrate/SKILL.md` 拆出（原文件 >9000 B，`skilllint` 告警）。

## 四节点 / 三任务 / 一条纪律

| 节点 | 语义 | 谁能写 |
|---|---|---|
| `goal` | 要达成什么（唯一） | 人 / 主会话 |
| `step` | 一个待执行的**探索方向**（不是计划，是"下一步试什么"） | 主会话 / `reason` |
| `fact` | **已确认的客观结论**（必须可复现） | 探索它的 Worker |
| `hint` | 人的判断，随时注入 | 只能是**人** |

`fgs next <pid>` 给出唯一答案，**这是调度不是建议**：

| 任务 | 条件 | 干什么 |
|---|---|---|
| `bootstrap` | 初始态（无 fact 无 step） | **直接解决问题，别先画计划** |
| `explore` | 有 `open` 的 step | 认领**一个**，执行，出一条结论 |
| `reason` | 没有 open、也没有 running 的 step | **读全图**：够了吗？下一步试什么？ |
| `wait` | 还有 step 在 `claimed` | 等收口 |
| `none` | 已 solved | 停 |

**唯一的硬纪律：`verified` 才算结论。**
只有 `verified` 的 Fact 能宣告 solved（`fgs solved` 会直接拒，退出码 3）。
`inferred` 是从输出推的，`unverified` 是怀疑 —— 都**不是**结论。
