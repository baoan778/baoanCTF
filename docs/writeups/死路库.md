# 死路库（跨题积累 · **别再走**）

> 手法库（`手法库.md`）管「**该怎么做**」；这里管「**这条路走不通**」。
> 两者都由 `board/retrospect.py` 的「候选 → 审核 → 合并」闸门写入（**人必须署名**），
> 来源是黑板上 `verified` 的**证伪结论**（`fgs publish` 投的「排除：…」事实）。
>
> **为什么值得单独记**：难题里最贵、别人最没有的资产就是「已经证伪的路线」——
> 同一类题的第二道，可以直接跳掉一整条路线。
> 但**宁缺毋滥**：没写清「现象 + 判据」的不要写（那就是一句抱怨，下一个人读了也不敢信）。
>
> 格式（`--merge` 自动按这个模板写；你只需在审核时补 `--generalize` 与 `--pitfall`）：

```markdown
### ✗ <走不通的路线>（一句话）
**走不通的路线**：看到什么信号会想到它 / 具体试了什么
**为什么（现象与判据）**：复现命令 + 反向输出 + 为什么它排除了这条路
**原始证据**：`f00N` <逐字结论>
**别再做**：什么条件下不用再试；该换哪个攻击面
**来源**：<项目id>（step sNNN / facts f00N）
```

> 这条库会被 `kb` 索引（`docs/writeups/**/*.md`），并**在 `fgs brief` 里单独提示**
> （「跨题死路库命中」一节）—— 所以新 Worker 起手就能看到，不用自己去搜。

### ✗ 越权/参数面全负：①admin.php 的替代鉴权矩阵（11 种 cookie 名 × 6 种取值 = 66 组合）**

**走不通的路线**：越权/参数面全负：①admin.php 的替代鉴权矩阵（11 种 cookie 名 × 6 种取值 = 66 组合）**禁跳转重测**全部 302（上一轮200是自己跟随了 302 的假阳性）；②admin.php 14 个 query 参

**为什么（现象与判据）**：门禁=session 角色时，替代鉴权（换 cookie 名 / 加 query 参数）必然全 302 —— 判越权必须**禁跟随重定向**（curl 不加 -L），否则 302→登录页 的 200 会被当成「未授权可达」的假阳性。

**原始证据**：
- `f008` 越权/参数面全负：①admin.php 的替代鉴权矩阵（11 种 cookie 名 × 6 种取值 = 66 组合）**禁跳转重测**全部 302（上一轮200是自己跟随了 302 的假阳性）；②admin.php 14 个 query 参数（admin/role/is_admin/debug/preview/upload/auth/key/level/type/source/show/grant）全 302；③index.php 25 个 GET 参数 + 11 个 POST 参数（search/q/keyword/all/private/draft/export/format=json 等）响应与基线**逐字节相同**；④flag 常见路径 14 个全 404；⑤PATH_INFO/编码变形（/admin.php/、//admin.php、/admin.php%00、;.php、大写）全 302/404 —— 门禁是 session 角色判定，不是 PHP_SELF 白名单。

**别再做**：已用禁跳转矩阵覆盖 66（cookie×值）+39（query 参数）组合后，不要再换 cookie 名/参数名重试；换攻击面（文件面 / 源码泄露 / 上传）。

**来源**：msgboard（step (f008 直投) / facts f008）


### ✗ 本地头与中央目录逐字段完全一致（flags/crc=0xa278a337/csize=235/usize=223 全相等

**走不通的路线**：本地头与中央目录逐字段完全一致（flags/crc=0xa278a337/csize=235/usize=223 全相等，csize-usize=12）→ 排除简单伪加密

**为什么（现象与判据）**：伪加密的判据是**本地头与中央目录的 flags 不一致**（bit0 / CRC / 压缩后大小）。逐字段完全一致 + csize-usize=固定开销 ⇒ 不是伪加密，这条快速排除。

**原始证据**：
- `f002` 本地头与中央目录逐字段完全一致（flags/crc=0xa278a337/csize=235/usize=223 全相等，csize-usize=12）→ 排除简单伪加密

**别再做**：比对一致就直接排除，去看真实 Crypto（ZipCrypto 已知明文对 / bkcrack），别再反复重读 zip 头。

**来源**：zip-revenge（step (f002 直投) / facts f002）
