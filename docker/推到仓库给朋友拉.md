# 把镜像推到国内仓库，朋友一条命令拉下来（最省事的给法）

> 镜像已在本机构建好：`pictf-webui:0.1.1`（约 3.5GB，拉取压缩后约 1.2GB）
> 推荐用阿里云容器镜像服务 ACR「个人版」（免费、国内拉取快）

## 一、你这边：推一次
1) 注册阿里云 → 容器镜像服务 → 个人版 → 开通 → 创建命名空间（如 `pictf`）与仓库（如 `webui`）
   控制台会给你一个地址，形如 `registry.cn-hangzhou.aliyuncs.com/pictf/webui`

2) 在 Windows PowerShell 里（Docker Desktop 已启动）：
```powershell
docker login registry.cn-hangzhou.aliyuncs.com     # 用户名=阿里云账号全名，密码=控制台设的镜像密码
docker tag pictf-webui:0.1.1 registry.cn-hangzhou.aliyuncs.com/pictf/webui:0.1.1
docker push registry.cn-hangzhou.aliyuncs.com/pictf/webui:0.1.1
```

## 二、朋友那边：两条命令
```powershell
docker pull registry.cn-hangzhou.aliyuncs.com/pictf/webui:0.1.1
docker run -d --name pictf -p 127.0.0.1:30142:30142 `
  --cap-add=SYS_PTRACE --security-opt seccomp=unconfined `
  -v pictf-agent:/home/ctf/.pi-ctf -v pictf-workspace:/opt/pi-ctf/workspace `
  registry.cn-hangzhou.aliyuncs.com/pictf/webui:0.1.1
```
浏览器开 http://127.0.0.1:30142/ → 模型页填他自己的 key。

## 三、朋友不拉镜像、自己构建也行
把 `PiCTF-WebUI-core-58M.zip` 解压 → 装 Docker Desktop → 在该目录：
```powershell
docker compose up -d --build     # 首次 10~20 分钟，全部走国内源
```

## 注意
- 镜像里**不含** PoC 语料；要 1.1 万条 PoC → 把 `PiCTF-PoC-知识包-43M.zip` 解压覆盖到目录后再 build
- 容器模式**不支持** Windows 侧 IDA/Ghidra（需要那个就用 WSL 方式）
- 更新镜像：本机重新 build 后 `docker push` 覆盖同一个 tag，朋友 `docker pull` 即更新
