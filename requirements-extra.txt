# ── sage（crypto 大格/Coppersmith/离散对数）★ 2026-11-04 ────────────────────
#   Ubuntu 24.04(noble) **已经没有 sagemath 包**（apt-cache policy → Candidate: none，
#   只剩 sagemath-database-* 数据包）。pip 上的 sagemath-standard 10.7 源码包要
#   现场编译 ~10 万行 Cython，在容器里不现实。
#   可用的路是 passagemath（sagemath 的 modular 发行版，纯 manylinux 轮子，不编译）。
#   ★ 「全量」装不上：passagemath-standard 依赖 python <3.12，与容器 3.12 冲突
#     （实测 ResolutionImpossible）。所以显式列模块，别写 passagemath-standard。
#   装完由 docker/sage-shim.sh 生成 sage.all / sage.all_cmdline —— 这两个是 sage
#   的「全量命名空间」，passagemath 各模块只提供 sage.all__sagemath_<模块>，
#   缺了它 `from sage.all import *` 与 `sage` 命令行都不工作（实测）。
